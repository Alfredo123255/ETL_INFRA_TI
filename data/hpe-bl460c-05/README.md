# hpe-bl460c-05

Simulador SNMPv3 BLADE HPE. Destino `127.0.0.25:18500`.

Usuario `HPE`, clave `Enterprise`; SHA/AES, contexto `public`.

Blade del chasis `hpe-c7000-02`, slot 2. Su identidad coincide con el hostname/FRU expuesto por el chasis para la asociación automática del ETL.

Datos de laboratorio basados en los perfiles MIB existentes. Arranque y apagado mediante `data/start_agents.bat` y `data/stop_agents.bat`.
